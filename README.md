# Rooftop Anthology

Пиксельная хроника зомби-апокалипсиса в изометрических диорамах.
Чистый JS + Canvas, без сборки и зависимостей: открывается из `index.html`
и работает на GitHub Pages.

- **Сюжет** — главы идут по порядку, у каждой своя локация и сценарий.
  Сейчас готова глава 1 «Обычный день» (городской парк).
- **Крыша · песочница** — исходная интерактивная крыша с 5 погодными сценариями
  (стартовый экран → «Крыша · песочница»).

Глава 1 начинается как кино, а когда в парке начинается паника,
управление героем переходит к игроку. Цель — добраться до восточных ворот.

| Действие | Клавиши |
|---|---|
| Бег | `WASD` или стрелки (работает и на русской раскладке) |
| Прицел | мышь |
| Выстрел | `ЛКМ` (12 патронов в магазине + 24 в запасе) |
| Удар (отталкивает и оглушает) | `ПКМ`, `Пробел`, `F` |
| Перезарядка | `R` |
| Пауза | `Esc` / `P` |
| Звук | `M` |

У героя 3 жизни. Попадание в голову убивает зомби сразу, в тело нужно два выстрела
или три удара. Выстрелы шумят и привлекают зомби поблизости.

## Структура

```
src/palette.js, pixelBuffer.js, iso.js   общий пиксельный движок
src/weather.js, audio.js                 облака/погода и звук (общие)
src/scenarios.js, architecture.js,
src/entities.js, ui.js                   песочница крыши
src/story/kit.js          проекция, запечённая земля, кровь (Decals), частицы, деревья
src/story/actors.js       толпа: люди, зомби, собаки, голуби, шарики, брошенные вещи
src/story/storyAudio.js   крики, укусы, рычание, тревожный гул, музыка
src/story/story.js        режиссёр: порядок глав, камера, тряска, затемнения, финал
src/story/chapters/       главы (ch1_park.js)
src/main.js               цикл кадров, переключение режимов, вывод на экран
```

## Как добавить главу

1. Скопируй `src/story/chapters/ch1_park.js` в новый файл, например `ch2_street.js`.
2. Поменяй шапку главы:
   `id`, `number`, `title`, `place`, `duration` (секунды), `nextTeaser`.
3. В `create(api)` опиши:
   - **локацию** — размеры `U`/`V`, запечённую землю (`bakeGround`),
     статичные предметы (`staticItems`), препятствия и выходы (`EXITS`);
   - **актёров** — `crowd.add({...})`; роли, внешность (`look`), скрипты
     (`crowd.setScript(a, [{type:'goto'...}, {type:'sit'...}])`);
   - **таймлайн** — `at(секунда, () => ...)`: появление зомби, укусы,
     `api.shake()`, `api.fade()`, звуки `sfx.*`;
   - **камеру** — функция `camera(t)` возвращает `{ x, y, zoom }`
     в пикселях буфера 480×270.
4. Подключи файл в `index.html` после `ch1_park.js`.
   Главы проигрываются в том порядке, в котором подключены.

Глава возвращает объект `{ update, render, camera, hours, audioMix, audioState }`.
`render` рисует весь кадр в буфер и возвращает `atmo` (палитру и освещение кадра).

### Полезные ручки в главе 1

- Сколько людей и где они: блок «Cast» в `ch1_park.js`.
- Насколько жёстко: `runSpeed` / `chaseSpeed` / `reactRange` / `gawkChance`
  (значения по умолчанию в `makeActor` в `actors.js`), волны зомби — `wave(...)`.
- Игровая часть: `CONTROL_AT` (когда управление переходит игроку), `GUN`
  (патроны), `hero.runSpeed`, урон в `shoot()` / `melee()`, ворота-цель —
  выход с `playerExit: true` в `EXITS`.
- Темп: моменты в `at(...)` и `duration`.
- Мрачность неба: `decayAt(t)` и цвета в `computeAtmo`.
