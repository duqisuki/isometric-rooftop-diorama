# Rooftop Anthology

Пиксельная хроника зомби-апокалипсиса в изометрических диорамах.
Чистый JS + Canvas, без сборки и зависимостей: открывается из `index.html`
и работает на GitHub Pages.

## Сюжет

| № | Глава | Когда | Что происходит |
|---|---|---|---|
| 1 | Обычный день | День 1, 14:20 | Парк. Первый укус. Оружия нет — минуту убегаешь, одно касание убивает. Врывается армейский грузовик. |
| 2 | Слишком много | День 1, 14:46 | Грузовик разбит на перекрёстке. Водитель-солдат отстреливается и гибнет. Подбери его автомат и прорвись к школе. |
| 3 | Школа | День 1, 15:20 | Первый этаж в разрезе: классы, коридор, столовая, библиотека. Доберись до лестницы на крышу. |
| 4 | Крыша | День 12, 18:40 | Та самая крыша из песочницы. Лагерь выживших, дверь лестницы выбивают, ливень. Продержись до темноты и уходи по пожарной лестнице. |
| 5 | Дом | День 30, 21:40 | Заколоченный дом, свечи. Костя скрыл укус. Пожар идёт по комнатам — выберись через чёрный ход. |
| 6 | Последний день | День 90, 06:10 | Город в огне и руинах, падает пепел. Пробейся к вертолёту. |

Смерть — затемнение и рестарт главы сразу с момента, где начинается управление.
После последней главы — возврат на стартовый экран.

**Крыша · песочница** — исходная интерактивная крыша с 5 погодными сценариями
(стартовый экран → «Крыша · песочница»).

## Управление

| Действие | Клавиши |
|---|---|
| Бег | `WASD` или стрелки (работает и на русской раскладке) |
| Рывок | `Shift` (тратит выносливость — полоска слева сверху) |
| Прицел | мышь (с главы 2) |
| Выстрел | `ЛКМ` |
| Удар (отталкивает и оглушает) | `ПКМ`, `Пробел`, `F` |
| Перезарядка | `R` |
| Пауза | `Esc` / `P` |
| Звук | `M` |

## Структура

```
src/palette.js, pixelBuffer.js, iso.js   общий пиксельный движок
src/weather.js, audio.js                 облака/погода и звук (общие)
src/scenarios.js, architecture.js,
src/entities.js, ui.js                   песочница крыши (её же рисует глава 4)
src/story/kit.js          проекция, запечённая земля, кровь, частицы, огонь, деревья,
                          дома, машины, грузовик, сетка поиска пути (A*)
src/story/actors.js       толпа: люди, зомби, собаки, голуби; погоня, укусы, обращение
src/story/storyAudio.js   крики, укусы, выстрелы, мотор, гудок, тревожный гул, музыка
src/story/stage.js        общий движок главы: игрок, бой, машины, волны, смерть, переходы
src/story/story.js        режиссёр: порядок глав, камера, затемнения, рестарт, пауза
src/story/chapters/       главы ch1 … ch6
src/main.js               цикл кадров, ввод, переключение режимов, вывод на экран
```

## Как добавить главу

1. Создай `src/story/chapters/chN_name.js` по образцу `ch3_school.js` (короткая и простая).
2. Опиши главу: `{ id, number, title, place, day, duration, retryAt, create(api) }`.
   `retryAt` — секунда, с которой глава перезапускается после смерти.
3. В `create` вызови `Diorama.Stage.create(api, cfg)`, где `cfg` задаёт локацию:
   размеры `U`/`V`, `bake` (пол и задние стены), `items` (предметы с сортировкой
   по глубине), `boxes`/`obstacles` (стены и препятствия), `exits`, `nav: true`
   для помещений, свет, погоду, камеру.
4. Добавь актёров (`S.crowd.add`), таймлайн (`S.at(сек, fn)`), передай управление
   (`S.control(hero, { armed, oneTouch, hp, timer, gun })`) и поставь цель
   (`S.marker` + выход с `playerExit: true` или свой вызов `S.win()`).
5. Подключи файл в `index.html` — главы идут в порядке подключения.
